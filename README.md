## 주요 프로젝트

### 현대자동차 소프티어 부트캠프 8기 – 데이터 엔지니어/아키텍트
- 데이터 아키텍처 및 데이터 엔지니어링 실무 교육 이수
- 요구사항 분석, 데이터 모델링 및 ERD 설계부터 Python·SQL 기반 데이터 처리, Hadoop·Spark를 활용한 분산 데이터 처리, Airflow 기반 데이터 파이프라인 설계, Docker 및 AWS 환경에서의 시스템 구축 학습
- DA 프로젝트: 전사 회의실 예약 시스템의 데이터 모델 설계
- DE 프로젝트: 서울시 따릉이 재배치 지원 시스템의 5분 주기 데이터 파이프라인 구축


### Real Estate Registry System
- 블록체인 기반 부동산 등기부등본 관리 시스템. 시간-속성-값 구조를 통해 부동산등기 정보 변경 이력 실시간 저장

### Stablecoin Risk Analysis
- 델타헷지형 스테이블 코인 Ethena USDe 구조 분석, 발행·체결 과정에서 발생할 수 있는 시간차와 가격차 리스크를 관리하는 시스템 구현
